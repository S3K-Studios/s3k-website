# S3K Studios Web Sitesi

## Çalıştırmak için

Öncelikle en son dev sürümlerile büyük değişiklik yapıldığı şiçin `node_modules` kalsörünü ve `package-lock.json` dosyasını silmeniz gerekmektedir. Ardından aşağıdaki komutları çalıştırabilirsiniz:

Bunu yapmak için:

```bash
rm -rf node_modules package-lock.json
```

Daha sonra:

```bash
npm install
```

Ardından projeyi çalıştırmak için:

```bash
npm run dev
```
